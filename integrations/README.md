# Integrations

- [`pi/soil`](pi/soil) — Pi extension for structural `.soil` reads, edits, checks, and checkpoints.
- [`pi/mush`](pi/mush) — Pi extension that swaps the session shell and file tools for Mush.
- [`cloudflare/confluence-edge`](cloudflare/confluence-edge) — Cloudflare Worker shim for the Confluence webhook relay.
